WHAT YOU ACTUALLY NEED

  Parts A, B and D    No computer at all. Paper and the worksheet.
  Part C              Python with numpy, pandas, matplotlib, scipy and
                      statsmodels, plus the CSV.

IF YOU CANNOT DOWNLOAD THE CSV
  You are not blocked. The green box at the start of Part C in the
  worksheet contains a short cell that generates the identical dataset
  on your own machine, with no download and no internet. Run that
  instead and continue as normal.

THE COMPANION NOTEBOOK IS OPTIONAL
  CS3621_TimeSeries_Companion.ipynb is the Lecture 1 reference
  notebook. It has worked code for every technique from the lecture,
  already run, with the outputs saved, so you can read it without
  running anything. Nothing in this practical requires it.
